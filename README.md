# SALIKA – Smart Ingredient & Kitchen Assistant

SALIKA (Smart Ingredient & Kitchen Assistant) is a Java-based desktop application designed to provide an intelligent and organized approach to kitchen management and recipe discovery.

The application allows users to manage ingredients, explore recipes, receive personalized recommendations, plan meals, track nutritional information, manage favorite recipes, and generate shopping requirements based on missing ingredients.

## Key Features

### Ingredient Management
- Store and manage available kitchen ingredients
- Organize ingredients using custom linked list data structures
- Track ingredient information for recipe matching

### Recipe Management
- Store and organize recipes
- Manage recipe ingredients and their requirements
- Display recipes through interactive recipe cards
- Organize recipes using a custom Binary Search Tree (BST)

### Smart Recipe Recommendations
- Compare available ingredients with recipe requirements
- Recommend recipes based on ingredient availability
- Identify missing ingredients
- Calculate recipe compatibility and recommendations

### Favorites Management
- Save and manage favorite recipes
- Custom data structure implementation for storing favorites

### Meal Planning
- Plan and organize meals
- Explore recipes for meal preparation

### Shopping Management
- Identify ingredients required for selected recipes
- Manage missing ingredients
- Assist users in preparing shopping requirements

### Nutrition Information
- Display and manage nutritional information related to recipes and meals

### Undo Functionality
- Track user actions
- Undo recent operations using a custom Stack implementation

### User Interface
- Java Swing-based graphical user interface
- Custom UI components and utility classes
- Recipe cards and organized application panels
- User-friendly kitchen management experience

## Project Architecture

The system is organized into multiple components responsible for different aspects of the application:

| Component | Responsibility |
|-----------|---------------|
| Ingredient Management | Stores and manages kitchen ingredients |
| Recipe Management | Handles recipe information and requirements |
| Recommendation Engine | Generates recipe recommendations |
| Meal Planner | Assists with meal organization |
| Shopping Manager | Manages missing ingredients and shopping needs |
| Nutrition Information | Handles nutritional data |
| Favorites | Stores favorite recipes |
| Action Stack | Supports undo functionality |
| Database Manager | Handles application data management |
| User Interface | Provides the graphical desktop interface |
